 ## **Largest ELement & smallest in an Array**  {***}

 


### Brute Force Approach (smallest Also Largest)

>  - We use Here Sorting Techniques (Bubbol Sort or Any Other)
>  - And the Last Element Of Sorted Array is Largest Element



```
class Solution {
public:
    int largest(int arr[], int n) {
        auto swapel = [](int &a , int &b) {
            int temp = a;
            a = b;
            b = temp;
        };
        
        for(int i = 0 ; i < n ; i++) {
            for(int j = 0 ; j < n - i - 1 ; j++) {
                if(arr[j] > arr[j+1]) {
                    swapel(arr[j], arr[j+1]);
                }
            }
        }
        return arr[n-1]; // return arr[0];
    }
};
```

## Better Solution 

> - Take Arr[0] as a Largest elemnt
> - Comapre it For largest Over All element and ``` If(arr[i] > largest) largest = arr[i]```
> - C

 
 ```
 class Solution {
    public : 

    int largest (int arr[] , int n){
        int largest = arr[0];
        for(int i = 0 ; i < n ; i++){
            if(largest < arr[i]){
                largest = arr[0];
            }
        }

        return largest;
    }
 }

 ```

 ## Optimal Solution

 > - Here We will use Priority Queue
 > - Here the maximum or largest element always in top 

 ```
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:

int largest( vector<int> &arr ){
    
   int n = arr.size();
   priority_queue<int> pq;

   for(int i = 0 ; i < n ; i++){
       pq.push(arr[i]);
   }

   return pq.top();
}

};  


```
